# Media workflows (optional)

Images and video are optional. A strong text post with real evidence beats a pretty image with a weak claim.

| Tool | What it's good for | How it's added | Limits |
|---|---|---|---|
| Native image generation (built into Grok Bot) | Illustrations in the brand style; use `docs/brand/originals/hero.jpg` as reference | Already available | Generated art can garble text — keep in-image text minimal; never present it as a screenshot or real data |
| Canva plugin | Layouts, resizing a design for many social sizes, brand checks | **You** install it and sign in from the card your bot shows | Needs your Canva account; some features/templates may require a paid Canva plan — the bot must ask before anything paid |
| Remotion plugin | Short programmatic videos (captions, animated diagrams) | **You** install it from the plugin card | Rendering needs a local Node toolchain; long renders take time |
| Native video generation | Short filmed-looking clips | Built in | Not for charts or text-heavy explainers |

## Rules for every media item
1. **Research first.** Media is made after the topic and evidence are chosen, never before.
2. **Approval.** Show the media with the exact post text; publishing requires fresh approval.
3. **Rights.** Use only your own assets, generated art, or properly licensed material. Don't recreate real people, logos, or trademarks without permission, and don't imply affiliation with X or xAI.
4. **Quality check.** Open the file, check for garbled text, artifacts, wrong aspect ratio (X in-feed: 16:9 or 1:1; header 1500×500), and file size.
5. **Honesty.** Illustrations must not look like real dashboards or real metrics.
