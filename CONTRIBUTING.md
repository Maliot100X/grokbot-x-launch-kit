# Contributing

1. Fork, branch, and run `bash scripts/verify.sh` before opening a PR.
2. Never commit real account data, live snapshots, tokens, or third-party skill content. Use fictional fixtures labelled as example data.
3. Keep the no-publish boundary: PRs adding auto-posting, DM automation, or session scraping will be declined.
4. Regenerate visuals with `node scripts/gen-assets.mjs`.
